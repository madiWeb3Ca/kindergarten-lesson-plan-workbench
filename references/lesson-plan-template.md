## 二、每段填写标准

| 段落 | 必须回答的问题 | 不合格信号 |
|---|---|---|
| 活动名称 | 孩子和家长能不能看懂今天干什么 | 写成"科学活动（一）"这种编号式 |
| 目标 | 活动结束能不能用眼睛判断达成 | 出现"培养""激发""感受""体会"后无具体行为 |
| 准备 | 材料明天能不能凑齐、数量够不够 | 写"若干""适量" |
| 过程 | 另一位老师能否照着上完 | 只有环节名，没有老师说什么、孩子做什么 |
| 反应预判 | 孩子乱了老师知道怎么办吗 | 只写"注意常规""及时引导" |
| 延伸 | 这次活动能不能接上下一次 | 写"回家和家长一起复习"这种空话 |
| 反思 | 下次改什么 | 写"本次活动效果良好" |

## 三、完整正例（中班科学）

```markdown
# 影子从哪里来

**班级**：中班　**人数**：24　**领域**：科学　**时长**：25 分钟
**设计者**：　　　**日期**：　　　**是否实际上过**：是

## 一、活动目标

1. 能在手电筒照射时，说出影子出现在物体的哪一侧（背光面）
2. 能用 2 种方法让同一个玩具的影子变大或变小（靠近／远离光源）
3. 愿意把自己的发现讲给同伴听

## 二、活动准备

- 材料：手电筒 6 支（每组 1 支）、白色卡纸 6 张、小动物玩具 6 个、黑色马克笔 6 支
- 环境：活动室拉一半窗帘，保证每组有一块背光墙面
- 经验准备：此前玩过"踩影子"户外游戏

## 三、活动过程

### （一）导入　约 4 分钟

- 老师：关掉一半灯，用手电筒照墙面，问"墙上这个东西是什么？它是从哪里来的？"（先不提"影子"两个字，让孩子自己说）
- 孩子：观察、猜测、说出"影子"
- 材料：**此时只发手电筒 1 支（老师用），玩具和卡纸全部不发**

### （二）展开

**环节 1　约 8 分钟：找影子在哪边**
- 老师：每组发 1 支手电筒、1 个玩具。提要求："先把玩具放在桌上，手电筒从左边照，影子在哪边？再换右边照，影子又去哪了？"
- 孩子：两人一组，一人照一人看，说出影子方位
- 材料：**先放玩具，再发手电筒**（先发手电筒会立刻玩光，不听要求）

**环节 2　约 9 分钟：让影子变大变小**
- 老师：提挑战"不换玩具，能不能让影子变大？"巡视时对做不出的组提示"把手电筒拿远一点试试"
- 孩子：尝试靠近／远离，发现规律
- 材料：卡纸和马克笔此时发，让孩子把影子轮廓描下来

### （三）结束　约 4 分钟

- 老师：请 3 组展示描下来的影子，问"你们是怎么把它变大的？"
- 孩子：说出"手电筒离得远／近"
- 收尾：影子图贴到科学区墙面，约定明天继续玩"影子剧场"

## 四、孩子可能的反应与应对

| 可能发生的情况 | 应对 |
|---|---|
| 孩子拿到手电筒就互相照眼睛 | 发之前先约定"手电筒只照墙和桌子，照到人立即收回"，并让每组小组长保管 |
| 有孩子说"我不会" | 给一个已描了一半的轮廓，让他接着描 |
| 两组争抢同一支手电筒 | 每组固定一支并贴组号，争抢时按组号归位 |

## 五、活动延伸

- 区域内：科学区投放手电筒和不同形状积木，玩"影子剧场"
- 家园：请家长晚上和孩子在灯下玩手影
- 下次衔接：大班"影子为什么会变长"（测量与记录）

## 六、安全提示

- 手电筒不得直射眼睛，中班需老师全程提醒；不使用激光笔
- 无小颗粒材料，无吞咽风险

## 七、活动反思（上完之后填）

- 环节 2 超时 3 分钟：孩子描轮廓比预期慢，下次把卡纸换成更大尺寸
- 目标 3 未完全达成：只有 5 组主动分享，下次改成"每组必须说一句"
```

## 四、反例对照

| 反例写法 | 问题 | 改法 |
|---|---|---|
| "培养幼儿的观察能力和动手能力" | 无法判断是否达成 | "能说出影子在背光的一侧" |
| "教师引导幼儿探索" | 没写怎么引、引到哪 | "提要求：手电筒从左边照，影子在哪边？" |
| "材料：树叶若干" | 数量不明，明天凑不齐 | "材料：银杏叶 60 片（每人 2—3 片）" |
| "注意幼儿常规，及时引导" | 等于没写 | "争抢时按组号归位，小组长保管" |
| "本次活动效果良好，幼儿参与积极" | 反思无信息 | "环节 2 超时 3 分钟，下次换大卡纸" |
| "回家与家长一起复习" | 家长不知道做什么 | "请家长晚上和孩子在灯下玩手影" |

## 五、常见扣分点

1. **导入就发材料**——孩子一开始玩，后面的提问全听不见
2. **目标写了四条以上**——一次活动撑不住，砍到 3 条
3. **环节时长加起来对不上总时长**——差 3 分钟以上就要重排
4. **小班活动超过 20 分钟**——注意力上限，写多了一定上不完
5. **没有经验准备**——孩子第一次接触，活动会卡在认知门槛上
6. **反思写成总结**——反思要写"下次改什么"，不是"这次多好"

## 六、HTML 输出与排版规范

教案默认交付 HTML，不是 Markdown：老师要的是能一眼看清、能打印带进教室的东西，不是源码感很强的文本。

### 生成方式

```bash
python scripts/render_html.py 教案.md          # 生成同名 .html
python scripts/scaffold_plan.py --class 中班 --domain 科学 --title "影子从哪里来"   # 默认直接出 HTML
```

HTML 是单文件、不依赖任何外部资源：不引在线字体、不放网络图片、不用脚本，断网双击也能正常打开和打印。

### 屏幕阅读

- 页面按 A4 宽度（210mm）居中，模拟真实纸张，避免老师判断不出打印效果
- 正文 16px、行高 1.75；环节里"老师/孩子/材料"三行用不同颜色的小标签区分
- 目标写成分条卡片并编号，教案里最需要反复看的就是目标
- `【待填】`自动黄底高亮，未填处一眼可见

### 打印

- 自带 `@page A4` 与 12mm 页边距，Ctrl+P 不用调设置
- 打印时字号降到 14.5px、间距收紧，一份 18—28 分钟教案通常排 2 页
- 每个环节卡片 `break-inside: avoid`，不允许把一张卡劈成两页
- 反思区留手写横线，打印出来可以直接用笔补
- 屏幕右上角有"打印 / 存 PDF"按钮，打印时自动隐藏

### 一条不能踩的边界

教案的**环节时长必须保留**（"约 3 分钟"这类）。对外课件、海报、宣传物料不留时间戳，但教案是执行方案，删掉时长老师就没法排课。两者不冲突，不要混用规则。
